# Đại Việt — tải bản máy tính

Đại Việt 1.3.39 — bản máy tính, kèm dữ liệu để chơi offline. Tiến độ lưu tại máy; có thể xuất/nhập JSON trong game để chuyển tiến độ từ bản web.

Bản này sửa pháo và đội thuyền theo chỉ huy ngay khi chuẩn bị, quân đã lên thuyền đi cùng thân thuyền, dáng bơi khi vào nước và nút quay về danh sách chiến dịch.

Chọn đúng hệ máy:

- macOS Apple Silicon (M1/M2/M3/M4…): `Dai-Viet-1.3.39-mac-arm64.dmg`.
- macOS Intel: `Dai-Viet-1.3.39-mac-x64.dmg`.
- Windows 10/11 x64: `Dai-Viet-1.3.39-Windows-x64-Setup.exe`.
- Ubuntu x64: `Dai-Viet-1.3.39-Ubuntu-x64.deb`.

macOS yêu cầu phiên bản 13 trở lên. Mở DMG và kéo Đại Việt vào Applications. Windows mở bộ cài Setup. Ubuntu mở tệp DEB bằng trình quản lý phần mềm hoặc dùng `sudo apt install ./Dai-Viet-1.3.39-Ubuntu-x64.deb`.

Các bộ cài chưa có chứng thư nhà phát triển: macOS ký ad-hoc, chưa notarize; Windows chưa ký số. Kết quả đóng gói không xác nhận đã chạy trên Windows/Ubuntu; xem `desktop-release.json` để biết đúng phạm vi kiểm chứng.

Game web: https://lac-hong-blood.vercel.app/?v=1.3.39

Mã băm đối chiếu các tệp tải xuống có trong `SHA256SUMS`. Dữ liệu game trùng bản web đã kiểm chứng: source SHA256 `2efcd491ccdd146998dc0e41c8277fd1b887382ed0ce6622c49128e32bb7f148`; product commit `0dca14d4d9791ed7b6671d2af4030a06ea1ed602`.

Đây là trò chơi mô phỏng lịch sử, có minh họa và quy ước sáng tác; không phải phục nguyên lịch sử đã được chuyên gia xác nhận.
